01 — 315개를 다 보고 0개

설치는 안 했지만 조사는 끝까지.

1. 전부 훑기공식 마켓 315개를 세 묶음으로 나눠 선별
2. 후보 추리기내 작업과 맞아 보이는 것만
3. 네 관점 검증사실 · 쓸모 · 비용 · 개인정보
4. 결론설치 0개, 부분 활용 몇 개
0개는 "플러그인이 나쁘다"는 뜻이 아니다. 이미 쓰는 도구·규칙과 겹치거나 부딪히는 게 많았다는 뜻이다. 대신 내 불편에 딱 맞는 스킬을 직접 만드는 쪽을 골랐다.

02 — 깔기 전에 묻는 4가지

하나라도 걸리면 일단 보류.

질문 1

토큰(키)을 발급해야 하나?

개인 액세스 토큰, 봇 토큰, API 키를 만들어 붙여 넣어야 쓰는가. 토큰 발급 방식은 쓰지 않기로 정했기 때문에 여기서 가장 많이 빠졌다.

질문 2

데이터가 밖으로 나가나?

내 화면·주소·대화·사진이 외부 서버로 가는가. 사용 통계를 보내는지, 기록을 어디에 쌓는지까지 본다.

질문 3

이미 있는 것과 겹치거나 부딪히나?

내장 기능이나 직접 만든 도구가 같은 일을 이미 하는가. 또 내 규칙(확인 후 커밋, 밝은 화면, 새 창으로 보여 주기)과 반대로 동작하지 않는가.

질문 4

켜 두기만 해도 비용이 드나?

쓰지 않아도 설명문이 매번 대화에 실리거나, 대화마다 자동 검토가 돌아 사용량을 먹지 않는가.

04 — 남은 후보는 '부분만·잠깐만'

통째로 설치보다 나았던 방법.

부분만

필요한 스크립트만 차용

웹앱 시험 묶음을 통째로 깔지 않고, 필요한 스크립트만 라이선스 표기와 함께 가져다 쓰기로 정했다.

잠깐만

큰 개편 뒤 한 번

오래 도는 보안 스캔은 상시 설치하지 않고, 큰 개편 뒤 꼭 필요할 때만 잠깐 켠다.

내장 먼저

이미 들어 있는 기능

스킬이 제때 켜지는지 시험하는 일은 공식 도구보다 내장 시험 기능을 먼저 쓴다.

05 — 언제 다시 볼까

0개는 지금의 답일 뿐.

  • ✓같은 불편이 세 번 이상 반복될 때 — 직접 만든 도구로도 안 풀리면 다시 찾아본다.
  • ✓토큰 없이 쓸 수 있게 바뀌었을 때 — 질문 1에서 빠졌던 연동은 이 조건이 풀리면 다시 본다.
  • ✓새 종류의 작업이 생겼을 때 — 예를 들어 문서 파일 작업이 생기면 그때 문서용 스킬을 조건과 함께 본다.

📚 더 깊이 — 강의용 상세

탭을 눌러 펼쳐 보세요.

'켜 두기만 해도' 드는 비용이란

플러그인이나 스킬은 쓰지 않아도 이름과 설명문이 매 대화에 실린다. Claude가 "지금 이걸 쓸까?"를 판단하려면 목록을 알아야 하기 때문이다. 하나하나는 작아도, 묶음으로 수십 개가 켜지면 대화마다 그만큼 읽을 양이 는다.

더 큰 비용은 자동으로 도는 기능이다. 대화마다 검토를 돌리거나, 모든 웹 작업 전에 먼저 실행되도록 적힌 것들은 쓸 때마다 시간과 사용량을 더한다. 그래서 질문 4는 "얼마나 자주, 나도 모르게 도는가"를 묻는 질문이다.

플러그인 하나를 4가지로 걸러 보기

  • 1) 설명서 읽기. 설치 안내에 "토큰", "API key", "personal access"가 있는가 → 질문 1.
  • 2) 어디로 보내나. 외부 주소로 보내는 기능, 통계 전송, 기록 저장 위치 → 질문 2.
  • 3) 내 것과 비교. 내장 기능·내 도구로 이미 되는가, 내 규칙과 반대로 동작하지 않는가 → 질문 3.
  • 4) 상시 비용. 설명문 길이, 자동 실행 조건 → 질문 4.
  • 5) 남았다면 통째로 대신 필요한 부분만, 필요할 때만 쓸 수 있는지 본다.

이런 데서 자주 헛돈다

  • ① 이름만 보고 설치. "github"이니 당연히 필요하겠지 → 설치해 보니 토큰 발급이 필수.
  • ② 기본값을 안 봄. 기본이 어두운 화면, 화면이 뜨는 브라우저, 바로 커밋 → 내 규칙과 정면 충돌.
  • ③ 묶음째 설치. 필요한 건 하나인데 열두 개가 따라온다.
  • ④ 한 번 정하면 끝. 조건이 바뀌면 답도 바뀐다. 다시 볼 기준을 적어 둔다.

지금 깔려 있는 것 점검 (5분)

  • 설치된 플러그인·스킬 목록을 열고 하나씩 네 질문에 표시해 본다.
  • 최근 한 달 동안 한 번도 안 쓴 것에 동그라미.
  • 동그라미 중 질문 4(상시 비용)에 걸리는 것부터 꺼 본다.
