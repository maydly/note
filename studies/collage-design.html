CHAPTER 01

구조 — 어떻게 쌓을 것인가

콜라주처럼 보여도 안에는 설계된 질서가 있다. 구조를 먼저 이해해야 자유롭게 부술 수 있다.

시각적 위계 (Visual Hierarchy) 핵심

무엇을 먼저 보게 할 것인지의 순서를 설계하는 것. 크기·명도·채도·위치로 1순위~3순위를 의도적으로 만들어야 한다. 아무것도 설계하지 않으면 눈이 어디를 봐야 할지 모른다.

VISUAL HIERARCHY — Electric Heart 포스터. 타이틀 → 사진 그룹 → 트랙 정보 순으로 위계가 설계되어 있다

  • 크기: 가장 직접적인 위계 도구. 타이틀은 본문의 2~3배 이상 차이를 줄 것
  • 명도·채도: 밝고 채도 높은 것이 먼저 읽힘. 배경을 낮추고 주인공을 올리는 구조
  • 위치: 좌상단 → 중앙 → 우하단 순서로 시선이 이동하는 경향 활용
···
근접성 (Proximity)

관련 있는 요소끼리 묶어서 하나의 덩어리로 읽히게 하는 것. 트랙 정보가 하나의 박스 안에 처리되거나, 가사 텍스트가 노트지 위에 올라가 있는 방식이 이 원리다.

  • 관련 없는 요소는 충분히 떨어뜨릴 것 — 간격 자체가 의미를 만든다
  • 텍스트+이미지가 같은 오브제(테이프, 종이) 위에 올라가면 자연스럽게 묶여 읽힘
레이어링 (Layering) 핵심

배경 → 중간 오브제 → 컷아웃 인물 → 텍스트 순으로 쌓아 깊이감을 만든다. 인물을 오려낸 것처럼 처리하는 것이 핵심.

아이즈원 콜라주 — 배경 사진 위에 인물 컷아웃, 텍스트가 층층이 쌓임

Wish for our Wish — 배경 사진, 찢긴 종이, 컷아웃 인물, 텍스트의 4중 레이어

  • 레이어 수가 많을수록 그림자·가장자리 처리가 중요해짐
  • 앞쪽 레이어는 선명하게, 뒤쪽은 흐리거나 어둡게 — 원근감 설계
그리드 vs 자유배치

콜라주처럼 보여도 실제론 보이지 않는 축이 있다. 완전 랜덤으로 놓으면 어지럽고 불안정해 보인다.

의도적 탈축과 실수적 탈축의 차이 — 수평 기준선 위에서 일부 요소만 기울이는 것이 자유로우면서도 안정적으로 읽히는 방식이다.
여백 처리

꽉 채우는 것과 숨통을 트는 것의 판단. 빽빽해 보이는 콜라주도 시선이 쉬는 지점이 반드시 설계되어 있다.

NEGATIVE SPACE — Wish for our Wish. 하단 베이지 공간이 텍스트와 오브제의 숨통을 만든다

  • 여백도 레이아웃 요소다 — 비어있는 공간이 다음 시선을 끌어당기는 역할을 함
  • 텍스트 주변 여백이 좁으면 답답하고, 너무 넓으면 요소들이 연결되지 않음
시선 흐름 (Gaze Flow)

인물의 눈 방향, 손 방향이 다음 요소를 가리키게 배치하는 것. 무의식적으로 읽히는 동선을 설계한다.

  • 인물이 오른쪽을 바라보면 → 오른쪽에 중요한 텍스트나 오브제 배치
  • 화살표, 선, 손가락 같은 방향성 있는 오브제도 시선 유도 도구로 사용 가능

CHAPTER 02

색 — 어떻게 맞출 것인가

색은 분위기를 결정한다. 규칙을 알아야 의도적으로 쓸 수 있고, 의도적으로 깰 수 있다.

근접보색 (Split-Complementary) 핵심

보색을 그대로 쓰면 촌스러워진다. 보색에서 30도씩 벗어난 두 색을 쓰는 것이 근접보색. 대비는 유지하면서 충돌을 피할 수 있다.

여름일기장 — 파랑 배경 + 노랑 포인트의 근접보색 조합

Campus Life — 파랑+노랑 고채도 근접보색. 강한 에너지감

예시 색 조합

#0047AB
#FFB347
#FF6B35
  • Adobe Color에서 'Split Complementary' 모드로 조합을 미리 확인 가능
  • 파랑(#0047AB) + 노랑-주황(#FFB347) 조합 → 충돌 없는 강한 대비
···
톤온톤 vs 포인트

배경과 주조색을 같은 톤으로 깔고, 포인트 색 하나만 강하게 튀기는 구조. 포인트 색은 한 가지만 — 두 개 이상이면 위계가 사라진다.

베이지 톤온톤 — 크림+오프화이트 베이스에 블랙 포인트

블루 톤온톤 — 파랑+화이트 베이스에 그린 포인트

  • 베이지+크림 베이스 → 블랙 포인트 (차분하고 세련된 느낌)
  • 블루+화이트 베이스 → 그린 포인트 (청량하고 생기있는 느낌)
  • 배경색 채도를 낮출수록 포인트 색이 더 강하게 살아남
사진 톤 통일

여러 사진을 섞을 때 색온도를 맞추는 것. 안 맞추면 콜라주가 아니라 그냥 사진 덩어리가 된다.

  • Photoshop Camera Raw로 모든 사진의 화이트밸런스·색조를 일괄 조정
  • 블렌딩 모드(Multiply, Overlay)로 배경 색감을 사진 위에 입히는 방법도 유효
  • 필름 느낌을 원하면 그레인 + 비네팅 레이어를 가장 위에 전체 적용

CHAPTER 03

타이포그래피 — 어떻게 읽힐 것인가

폰트는 말투다. 무엇을 쓰느냐가 아니라 어떻게 배치하느냐가 더 중요하다.

폰트 대비 핵심

손글씨체 + 세리프체 + 고딕체를 한 화면에 섞되, 2~3종 이하로 제한한다. 비슷한 성격의 폰트 두 개는 어울리는 것처럼 보이지만 오히려 어색하다.

FONT CONTRAST — Summer is Leaving. 손그림 대문자 + 필기체 + 프린트 서체 3종 조합

  • 이탤릭 세리프 타이틀 + 손글씨 가사 + 스탬프 텍스트 — 성격이 완전히 다른 조합
  • 한글+영문 페어링: 눈누(noonnu.cc) + Google Fonts 조합으로 연습
  • 폰트 3종 이상 쓰면 통일감 없이 산만해지는 경우가 많음 — 2종 조합 먼저 연습
추천 조합
한글 손글씨 (잉크립퀴드, 카페24 써라운드) + 세리프 영문 (Playfair Display, Cormorant Garamond)
고딕 (Noto Sans KR, 프리텐다드) + 손글씨 영문 (Caveat, Shadows Into Light)
···
크기 점프

타이틀과 본문의 크기 차이를 크게 줄 것. 비슷한 크기로 여러 줄 쓰면 모두 같은 중요도로 읽혀 아무것도 강조되지 않는다.

여름일기장 — 타이틀이 본문 대비 4~5배 크게 점프

Forever Young — FOR EVER / YOUNG의 크기 위계 설계

  • 최소 1.5배, 강한 위계를 원하면 3~4배 차이도 유효
  • 크기가 비슷하면 굵기(Bold)나 색으로 위계를 보완
텍스트의 방향과 배치

텍스트를 오브제로 다루는 것. 똑같이 수평으로만 배치하면 재미가 없다.

TEXT AS OBJECT — Campus Life. 테이프 위 대문자 텍스트, 기울어진 날짜, 손글씨 메모가 각각 다른 방향으로 배치됨

  • 비스듬히 기울이거나, 세로로 눕히거나, 찢긴 종이 위에 올리는 방식
  • 가사/인용구는 손글씨처럼 자유롭게, 정보성 텍스트는 타이트하게 정렬
  • 텍스트 색을 배경과 유사하게 처리하면 은근하게 깔리는 레이어 효과

CHAPTER 04

소재와 질감 — 무엇으로 채울 것인가

질감이 온도를 만든다. 같은 구도라도 질감이 다르면 전혀 다른 느낌이 된다.

텍스처 레이어 핵심

종이 찢김, 마스킹 테이프, 스탬프, 필름 그레인 등이 콜라주의 온도감을 만든다.

TEXTURE LAYERS — 손글씨 텍스트, 찢긴 종이, 사진 경계가 겹치며 만드는 콜라주 질감

  • 직접 스캔: 실제 종이, 테이프, 천 등을 600dpi 이상으로 스캔 → 진짜 질감
  • 브러시 활용: Photoshop/Procreate의 종이 텍스처 브러시로 유사하게 구현
  • 텍스처 레이어의 블렌딩 모드를 Multiply나 Overlay로 설정하면 자연스럽게 합쳐짐
···
컷아웃 처리 퀄리티

누끼 따는 방식에 따라 완성도가 달라진다. 가장자리 처리가 전체 느낌을 결정한다.

자동 선택

빠르지만 머리카락·복잡한 배경에서 품질 저하. 빠른 작업용.

Select Subject + Refine Edge

중간 품질, 적당한 속도. 실용적인 선택.

채널 마스크

머리카락 한 올까지 살릴 수 있음. 퀄리티 최상.

잘린 가장자리를 일부러 거칠게 처리하면 콜라주 느낌이 강해진다. 의도적 불완전성도 선택지다.
오브제 선택 감각

스탬프, 별, 테이프, 체리, 카세트 등은 단순한 장식이 아니라 콘셉트를 설명하는 기호다. 오브제 하나가 시대감·무드·취향을 한번에 전달한다.

ITZY — 체리, 카세트, 폴라로이드, 핑크 전화기. 90s 슬럼버파티 세계관을 오브제로 설명

Electric Heart — 우표, 나비, 폴라로이드. 편지+자연 세계관을 오브제로 설명

  • 오브제 하나가 시대감, 무드, 취향을 한번에 전달함 — 선택 자체가 편집 행위
  • 콘셉트와 언어가 다른 오브제 하나가 전체 세계관을 깨트릴 수 있음
  • 레퍼런스에서 어떤 오브제를 쓰는지 따로 기록하는 습관이 유효 — 취향 언어 축적

CHAPTER 05

도구와 작업 흐름

도구를 모르면 머릿속 이미지를 꺼낼 수 없다. 핵심 기능만 알아도 80%는 된다.

Photoshop — 핵심 기능 필수
  • 블렌딩 모드: Multiply(겹치기), Screen(밝히기), Overlay(대비 강화) — 사진 톤 합칠 때 필수
  • 스마트 오브젝트: 원본 훼손 없이 수정하는 비파괴 작업 — 항상 습관화할 것
  • Camera Raw: 여러 사진의 색온도·노출·채도를 일괄 통일할 때 사용
  • Refine Edge / Select & Mask: 인물 컷아웃 품질을 결정하는 핵심 기능
  • 클리핑 마스크: 오브제 안에 다른 이미지를 가두는 방식 — 텍스트 안에 텍스처 넣을 때 사용
···
Procreate — 손그림 요소

낙서, 화살표, 밑줄, 별 등을 직접 그려 넣는 능력. 콜라주 포스터의 온도감 상당 부분이 여기서 만들어진다.

HAND-DRAWN ELEMENTS — Forever Young. 흰색 낙서, 하트, 별, 밑줄이 디지털 위에 손온도를 더함

  • PNG(투명배경)로 내보내서 Photoshop에 레이어로 가져오는 워크플로우 구축
  • 브러시 팩 구매/수집: 마커, 연필, 크레용 등 질감이 다른 것을 여러 개 확보
  • Procreate 없이 Photoshop 브러시만으로도 구현 가능 — Kyle Webster 브러시 팩 추천

CHAPTER 06

감각적 판단력 — 어떻게 키울 것인가

감각은 타고나는 것이 아니라 쌓이는 것이다. 언어화할 수 있어야 재현할 수 있다.

레퍼런스 언어화 능력 핵심

왜 좋은지 말로 설명할 수 있어야 재현 가능해진다. '감각적이다'로 끝나면 발전이 없다.

  • 좋다고 느낀 포스터 → '무엇이 먼저 보이는가 / 왜 그게 먼저 보이는가' 직접 써보기
  • 색 조합 분석: 쓰인 색의 HEX값을 추출해서 기록하는 습관 (Adobe Color로 추출 가능)
  • 폰트 이름 알아두기: 좋아 보이는 폰트를 보면 WhatTheFont로 이름 확인
···
콘셉트 일관성

요소 하나하나가 달라도 전체가 하나의 세계관으로 읽혀야 한다. 색·질감·폰트·오브제가 같은 언어를 쓰고 있는지 항상 확인.

여름일기장 — 블루 배경, 나뭇잎, 연필, 노트지. 모든 오브제가 '여름방학 일기' 언어로 통일

ITZY — 체크무늬, 카세트, 체리, 폴라로이드. 모든 요소가 Y2K 슬럼버파티 세계관

  • 작업 전 무드보드 먼저 만들기 — 방향이 흔들릴 때 기준점으로 사용
  • 요소를 추가하기 전: '이게 지금 이 화면의 언어와 맞는가' 질문 하나 먼저
  • 완성 후 전체를 축소해서 보기 — 세부보다 전체 인상이 먼저 결정됨
단계별 훈련 순서 로드맵
  1. 레퍼런스 10~20장 모아서 위계 순서 손으로 써보기
    '1번째로 보이는 게 뭔지, 왜 그런지' — 설명할 수 있어야 재현 가능
